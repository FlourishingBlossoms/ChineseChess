
1. 启动服务端

Visual Studio 打开服务端项目，按 F5 运行
看到"监听端口8090"后，窗口不要关
2. Build 一个客户端 exe

Unity 中 File → Build Settings
把开始界面和游戏界面两个场景都加进 Scenes In Build
点 Build，选个文件夹（比如桌面新建 ChessBuild）
等待 Build 完成
3. 开两个客户端

双击 ChessBuild/xxx.exe 运行 → 这是客户端A
Unity Editor 里按 ▶ → 这是客户端B
3.我现在的要求是：房间列表始终显示，点击创建房间时向Scroll View里的Content添加房间列表预制体，通过点击预制体加入房间，将加入房间改为点击后跳出搜索框，通过输入id搜索房间。
4.搜索框是代码动态生成的，不需要你在 Unity 里搭建。点击"加入房间"按钮后弹出一个 400×220 的对话框：

Text


        
┌──────────────────────────┐
│       输入房间ID                                           │
│                                                                     │
│  ┌──────────────────┐              │
│  │ 请输入房间ID...                      │              │
│  └──────────────────┘             │
│                                                                    │
│  [确认]        [取消]                                       │
└──────────────────────────┘

      
只能输入数字（ContentType.Integer）
点"确认"→ 发送 JoinRoom 请求 → 关闭搜索框
点"取消"→ 关闭搜索框
